# Shay 作品集改版说明

## 目标

面向 FDE / AI 应用交付 / 前端 UI 方向求职，展示 Shay 从业务问题梳理、AI 产品设计、前端实现到内容增长验证的完整能力。网站本身也作为前端 UI、审美与动效能力的作品。

## 核心叙事

1. **EcomLens AI**：以评论证据驱动经营洞察、优先级判断和 Listing 优化，展示完整可运行的 AI 应用闭环。
2. **虚拟手机交互界面**：用 CSS 与正则规则实现消息、语音、撤回、转账卡片、状态栏和音乐播放器等前端交互。页面中的金额与对话均为虚拟演示内容。
3. **内容与增长实验**：展示 AI 智能体平台衍生账号和独立增长账号的公开主页、作品与后台数据，用真实截图证明内容运营和数据复盘能力。
4. **电商用户购买意图研究**：从毕业论文中提炼数据、方法、模型指标、洞察与业务启示，形成可读的研究案例，而不是论文摘要。
5. **实习与内容交付**：以活动照片、公开账号页面、发布记录、脚本表和署名截图形成证据墙，体现现场协作、内容策划和交付能力。

## 页面结构

- Hero：Shay、方向定位、生活照、项目入口和联系方式。
- Selected Work：EcomLens、虚拟手机交互、内容增长三组重点案例。
- Research：购买意图识别与转化预测研究。
- Field Notes：学校活动与微视河南相关工作证据图库。
- About / Contact：生活照、能力标签、手机号、微信、邮箱；不展示简历下载。

## 视觉方向

- 从个人照片提取奶油白、焦糖棕、橙红、深墨色，并以钴蓝作为科技感强调色。
- 保留强层级、非对称版式、大标题与精细微交互，避免通用模板感。
- 图片先全部进入可点击图库，后续再依据页面节奏删减。
- 动效服务于叙事：入场、悬停、卡片弹跳、横向轨道、灯箱切换；同时尊重 `prefers-reduced-motion`。

## 公开信息边界

- 不出现“保密项目”等标签。
- 虚拟转账明确标注为前端模拟，不暗示真实交易。
- Shay 自己的小红书昵称保留；其他用户信息沿用原截图中的遮挡。
- 含学生或活动参与者的画面采用小尺寸、柔化处理，不作为主视觉大图。
- 不公开后台业务数据、平台链接、客户信息或无法证明的指标。
